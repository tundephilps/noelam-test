# Frontend Developer Assessment

Student Management Dashboard assessment for the Frontend Developer role.

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/noelams/frontend-developer-assessment.git
cd frontend-developer-assessment
npm install
```

Start the development server:
```bash
npm run dev
```

Mock API

The project uses MSW (Mock Service Worker) to provide a local mock API. No external backend or database is required.

The mock data and API handlers are located in:
```bash
src/mocks/
```

Submission

Create your own GitHub repository containing your completed solution and submit the repository URL.

Your repository should be runnable with:
```bash
npm install
npm run dev
```
